## 🎯 1. Course Overview & Target Stack
- **Core Focus:** Modern Web Development with JavaScript / TypeScript (Single Page Applications).
- **Frontend:** React, Next.js, React Native, Zustand.
- **Backend:** Node.js, Express 5, RESTful APIs, GraphQL (Apollo Server v5 / Client v4).
- **Databases & DevOps:** Relational Databases (PostgreSQL/Sequelize), Docker Containers, CI/CD pipelines.
- **Cost & Certification:** 100% Free course, Free Certificate, and Free University ECTS Credits (Open University).

## ⚠️ 4. Critical Submission Rules (Must Read!)

1. **One-Time Part Submission:**
   - Always submit **one part at a time**.
   - **Crucial Rule:** Once you submit a part in the submission portal, **you cannot add or edit exercises for that part anymore**. Finish everything you intend to do before clicking submit!
2. **Repository Strategy:**
   - You can push all parts into this single repository using separate subdirectories (`part0`, `part1`, etc.).
   - If your repository is **Private**, you **MUST** add `mluukkai` (Course Teacher) as a GitHub Collaborator.
3. **Plagiarism Detection:**
   - Submissions are analyzed with an automated anti-plagiarism system. Code must be written by you.
4. **Asterisk (*) Rule in Parts 1–4:**
   - Non-asterisk exercises are compulsory to pass to the next stage.
   - Asterisk-marked exercises contribute to a higher final grade.

## 🎓 5. Certificates vs. Official ECTS Credits

### A. Free Course Certificate (Recommended & Simplest)
- Once enough exercises are completed on the [Submission Portal](https://studies.cs.helsinki.fi/stats/courses/fullstackopen), download the official certificate directly from the **"My submissions"** tab.
- **No exam or Finnish registration needed.**

### B. University of Helsinki ECTS Credits (Official Transcript)
1. Complete exercises for $\ge 5$ credits.
2. Register via Open University (generates a Student Number).
3. Save Student ID in the submission system.
4. Take the **120-minute online exam** in the system (Pass/Fail; re-take allowed after 7 days).
5. Press the **"Ask for course completion credits"** button **TWICE** until `University credit registration in progress...` appears.
6. Order an official electronic verified transcript via Student Services e-form.

## 💬 6. Discord Help Etiquette

- **Channel Link:** [Full Stack Open Discord](https://study.cs.helsinki.fi/discord/join/fullstack)
- **Asking Effective Questions:**
  Never ask: *"Exercise X doesn't work, help me!"*
  **Always provide:**
  1. Exact exercise number (e.g., `Exercise 2.15`).
  2. Clear error description & HTTP status code (e.g., `403 Forbidden`).
  3. Formatted code snippet with `console.log()` debugging points.
  4. Screenshot of the Browser Console / Network Tab.
  5. Link to your GitHub repository/commit.
