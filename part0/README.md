# 🚀 Full Stack Open - University of Helsinki
This is my personal journey through the Full Stack Open course to master modern web development.

## 📌 Course Overview
- **Focus:** Single-page applications (SPA) with React, Node.js, Express, and GraphQL.
- **Topics:** TypeScript, React Native, CI/CD, Docker, Relational Databases, and Next.js.
- **Methodology:** Mastery Learning (Complete exercises before moving to the next part).

## 🛠 Tech Stack & Environment
- **OS:** Linux (WSL2 - Ubuntu)
- **Editor:** VS Code
- **Runtime:** Node.js v24 (LTS recommended)
- **Browser:** Chrome / Firefox Developer Edition

## 📂 Curriculum Map
- [ ] **Part 0:** Fundamentals of Web apps
- [ ] **Part 1:** Introduction to React
- [ ] **Part 2:** Communicating with server
- [ ] **Part 3:** Programming a server with NodeJS and Express
- [ ] **Part 4:** Testing Express servers, user administration
- [ ] **Part 5:** Testing React apps, React Router
- [ ] **Part 6:** Advanced state management
- [ ] **Part 7:** Custom hooks, esbuild
- [ ] **Part 8:** GraphQL
- [ ] **Part 9:** TypeScript
- [ ] **Part 10:** React Native
- [ ] **Part 11:** CI/CD
- [ ] **Part 12:** Containers
- [ ] **Part 13:** Using relational databases
- [ ] **Part 14:** Next.JS
